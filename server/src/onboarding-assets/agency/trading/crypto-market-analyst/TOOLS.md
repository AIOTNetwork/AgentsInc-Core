# Tools

## Installed Skills

### market-forecast
Comprehensive crypto market forecast using SOP v8.1 framework. Vegas Channel + Fibonacci + Micro + SM + Macro data fusion with regime-adaptive sizing. Multi-asset: BTC, ETH, BNB across 12h/24h/36h/48h timeframes.

Trigger: "分析走勢", "預測走勢", "market forecast", "/forecast"

### futures-microstructure
Deep micro-structure analysis for altcoin perpetual futures. Fetches Binance futures data (premium, OI, L/S ratios, taker flow, depth, aggTrades, funding, klines). Produces GAP analysis, OI+Price cross signals, MM phase detection, whale trade detection.

Trigger: "V3 分析", "合約微觀分析", "深度分析", "futures microstructure"

### orderbook-analysis
Binance Futures order book deep analysis for support/resistance identification, wall detection, spoofing detection, and trade execution optimization.

Trigger: "分析掛單簿", "orderbook", "支撐阻力在哪", "大牆"

### smart-money-analysis
Interpret Nansen smart money data, Hyperliquid perp positioning, on-chain whale movements, exchange flows, and ETF data to determine institutional direction.

Trigger: "Smart Money 怎麼看", "機構持倉", "大戶動向", "聰明錢", "whale alerts"

### funding-settlement
Analyze and trade around Binance Futures funding rate settlements. Detect pre-settlement manipulation and post-settlement reversal patterns.

Trigger: "funding 交割", "資金費率", "funding settlement"

### prediction-journal
Track, verify, and learn from market predictions. Maintains a running journal of forecasts and outcomes to improve accuracy.

Trigger: "/verify predictions", "預測準嗎", "prediction accuracy"
