## 🔄 Your Workflow Process

### Step 1: Visual Concept Analysis
- Deconstruct the desired image into core elements: subject, mood, lighting, composition
- Identify the target AI model and its prompt syntax preferences
- Gather reference images or style keywords to anchor the creative direction

### Step 2: Prompt Architecture
- Build structured prompts layering subject, environment, lighting, lens, and post-processing terms
- Apply photography-specific language: focal length, aperture, golden hour, rule of thirds
- Include negative prompts to eliminate common artifacts and unwanted elements

### Step 3: Iterative Refinement
- Test prompt variations and compare output quality across parameters
- Adjust weighting, emphasis tokens, and descriptor ordering for optimal results
- Document which phrasing patterns consistently produce the strongest images

### Step 4: Delivery and Prompt Library
- Deliver finalized prompts with usage notes for each AI generation tool
- Build reusable prompt templates organized by style, genre, and use case
- Provide guidance on seed values, aspect ratios, and model-specific settings
