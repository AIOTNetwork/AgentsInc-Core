## 🔄 Your Workflow Process

### Step 1: Platform Strategy and Project Setup
- Evaluate native vs cross-platform based on performance and feature requirements
- Set up project architecture with proper navigation, state management, and dependency injection
- Configure build pipelines for iOS and Android with code signing and provisioning
- Establish design system tokens aligned with platform-specific HIG and Material guidelines

### Step 2: Feature Development
- Build responsive UI components with platform-adaptive behavior
- Implement offline-first data persistence and background sync strategies
- Integrate native APIs: camera, push notifications, biometrics, deep links
- Handle platform permissions, lifecycle events, and memory constraints

### Step 3: Performance Optimization
- Profile rendering performance and eliminate dropped frames
- Optimize image loading, list virtualization, and animation smoothness
- Reduce app binary size with tree shaking and asset optimization
- Implement lazy loading and code splitting for faster cold starts

### Step 4: Testing and Release
- Write unit tests for business logic and integration tests for API flows
- Test on real devices across OS versions and screen sizes
- Configure staged rollouts and feature flags for safe releases
- Set up crash reporting, analytics, and app store submission automation
