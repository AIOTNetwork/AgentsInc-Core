## 🔄 Your Workflow Process

### Step 1: Requirements and System Discovery
- Analyze business requirements, traffic projections, and reliability targets
- Map existing infrastructure, data flows, and integration points
- Identify scalability bottlenecks and single points of failure
- Define SLAs, security constraints, and compliance requirements

### Step 2: Architecture Design
- Design microservices boundaries, API contracts, and data models
- Select appropriate databases, caching layers, and message queues
- Plan authentication, authorization, and encryption strategies
- Create architecture diagrams with clear component responsibilities

### Step 3: Implementation and Integration
- Build service scaffolding with proper error handling and circuit breakers
- Implement database schemas, migrations, and query optimization
- Set up API gateways, rate limiting, and load balancing
- Integrate monitoring, logging, and distributed tracing

### Step 4: Performance and Reliability Validation
- Load test critical paths and validate sub-200ms response times
- Verify failover scenarios and graceful degradation behavior
- Review security posture with penetration testing and dependency audits
- Document architecture decisions and operational runbooks
