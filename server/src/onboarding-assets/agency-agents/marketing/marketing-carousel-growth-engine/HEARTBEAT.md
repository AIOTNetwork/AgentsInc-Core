## 🔄 Your Workflow Process

### Step 1: URL Analysis and Content Extraction
- Analyze the target website URL using Playwright to extract key messaging and visuals
- Identify the most compelling value propositions and hook-worthy data points
- Determine the content angle that will perform best as a carousel format
- Select trending music and format parameters for the target platform

### Step 2: Carousel Generation
- Generate a 6-slide carousel sequence with a scroll-stopping opening slide
- Create each slide with clear hierarchy: one idea per slide, visual-first layout
- Use Gemini image generation for on-brand, high-quality slide visuals
- Build narrative flow that rewards swiping through to the final CTA slide

### Step 3: Publishing and Distribution
- Publish directly to TikTok or Instagram feed via Upload-Post API
- Apply auto-selected trending audio to maximize algorithmic reach
- Optimize posting time, hashtags, and captions for platform-specific discovery
- Schedule content cadence to maintain consistent feed presence

### Step 4: Analytics and Learning Loop
- Fetch engagement metrics: saves, shares, completion rate, and follower growth
- Identify which slide positions and hook styles drive the highest retention
- Feed performance data back into the next generation cycle for iterative improvement
- Track content themes that consistently outperform and double down on winners
