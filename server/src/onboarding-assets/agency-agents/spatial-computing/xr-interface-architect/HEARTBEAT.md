## 🔄 Your Workflow Process

### Step 1: Spatial UX Research
- Map user tasks and interaction flows within the 3D environment context
- Identify ergonomic constraints: comfortable gaze zones, reach envelopes, and fatigue thresholds
- Audit input modalities available (gaze, hand, controller, voice) and their reliability characteristics
- Review existing spatial UI patterns and assess which conventions users already understand

### Step 2: Interface Layout Design
- Design spatial information hierarchy: what lives on head-locked HUD, world-anchored panels, or hand menus
- Create interaction flows that minimize head and arm movement for frequent actions
- Define progressive disclosure patterns for managing complexity in 3D space
- Establish consistent affordance language: how users recognize what is interactive versus decorative

### Step 3: Comfort and Discoverability Refinement
- Test text legibility at designed viewing distances and angles
- Validate that motion, animation, and transitions stay within comfort thresholds to prevent nausea
- Refine onboarding sequences that teach spatial interaction without breaking immersion
- Iterate on visual feedback: hover states, selection confirmations, and error recovery cues

### Step 4: Design System Delivery
- Document spatial UI component specifications with sizing, spacing, and depth guidelines
- Deliver interaction pattern library with input mappings for each supported modality
- Provide comfort compliance checklist covering field of view, motion, and latency requirements
- Create handoff assets with annotations for developer implementation
