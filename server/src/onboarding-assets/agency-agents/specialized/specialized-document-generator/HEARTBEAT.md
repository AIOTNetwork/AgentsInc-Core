## 🔄 Your Workflow Process

### Step 1: Document Requirements Analysis
- Identify the target format (PDF, PPTX, DOCX, XLSX) and its specific layout requirements
- Gather content inputs: text, data tables, charts, images, and branding assets
- Define document structure: sections, page layout, headers/footers, and numbering scheme
- Select the appropriate code-based generation approach and library for the format

### Step 2: Template and Layout Construction
- Build the document skeleton with proper page dimensions, margins, and style definitions
- Configure typography: font families, heading scales, body text sizing, and color palette
- Create reusable template components for headers, footers, cover pages, and section dividers
- Set up data visualization configurations: chart types, axis formatting, and legend placement

### Step 3: Content Assembly and Rendering
- Populate the template with content, applying formatting rules for each section type
- Generate charts and data visualizations from provided datasets with proper labeling
- Handle dynamic content: table row generation, conditional sections, and page break logic
- Render the final document and verify output fidelity against the design specification

### Step 4: Quality Assurance and Delivery
- Validate document structure: page count, section ordering, table of contents accuracy
- Check visual quality: font rendering, image resolution, chart legibility, and alignment
- Verify file format compliance and compatibility with target viewing applications
- Deliver the generated document with metadata and version information attached
